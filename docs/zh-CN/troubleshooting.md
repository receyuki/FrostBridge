# 故障排查

[English](../en/troubleshooting.md) · [简体中文](troubleshooting.md) · [安装](getting-started.md)

| 现象 | 检查／下一步 |
|---|---|
| 没有串口 | 使用数据线、换USB口、安装板厂驱动；Linux可能需udev/用户组权限。运行`python3 frostbridge.py ports`。 |
| 串口忙／刷写失败 | 关闭监视器、IDE串口与配网窗口，按板厂BOOT/EN步骤重试，明确选择实际端口。 |
| 缺Python模块 | 运行`setup`，不要混用其他项目虚拟环境；doctor检查本机工具，不打开USB。 |
| 首次构建下载慢／中断 | 工具链需联网和数GB空间。下载失败后PlatformIO会尝试其他包镜像；若最终报错退出，解决网络／空间问题后重跑原build命令，不需要开发者缓存或擦除板子。 |
| 构建后只有smoke输出 | 使用gateway/gateway_zh；basic、coexistence、readout是诊断环境。 |
| Wi-Fi未连上 | 核对2.4GHz个人网络、SSID/密码字节限制和网络可达性。用wifi配网，只有SSID错可用--keep-password；不要公开密码。 |
| .local无法解析 | 在路由器查当前ESP32地址，用http://IP；访客网络/VLAN可能隔离mDNS。 |
| .local显示HTTP 502，但IP能打开 | 检查浏览器／系统代理和PAC；代理可能无法解析仅局域网可用的.local域名。使用设备当前IP，或在代理软件中为frostbridge.local设置DIRECT直连规则。重新刷写或配网不能修复代理路由。 |
| 浏览器尝试HTTPS | 明确输入http://后存书签/主屏幕图标；当前固件不提供TLS。 |
| 冰箱离线／读数过期 | 核对供电、距离、原厂App/nRF占用、所选目标与实际协议。保留旧值但不能当新鲜数据。bind默认保留目标，--replace才明确更换。 |
| 绑定后没新鲜状态 | 相同广播服务不代表兼容；核对型号、固件和本地日志。bind不会请求改变制冷设置。 |
| 二维码页没打开 | 打开pair打印的本地HTML路径，或在桌面运行时不加--no-open。用iPhone/iPad的家庭App扫，不是Wi-Fi设置；也可手动输入设置码。 |
| 家庭找不到配件 | 先完成Wi-Fi；手机/网关/中枢处于可互通局域网，开启手机蓝牙，检查组播隔离。 |
| 提示已加入其他家庭 | 有原家庭权限时先从其移除。读取设置码不会清除家庭，不要先擦除Wi-Fi/冰箱绑定。 |
| 操作成功但HomePod说无回应 | 查看新鲜状态与网页/家庭错误；已有发布/时序修复，但自然语音回归验收仍待。不要频繁启停冰箱来复现。 |
| 备用没有样本 | 默认关闭，先明确开启；开启当天不完整，等待连续完整UTC+8自然日并查看缺口原因。 |
| 样本日期较旧 | 已知缺口会保留上一有效样本，界面显示日期/年龄与未更新原因，不能当成昨天的计划。 |
| 空白样本 | 完整日没有自动化动作会替换旧样本，备用不主动改变设备。 |
| 断电后等待校时 | 没有后备RTC，等待NTP或用时间准确的手机/电脑校时。 |
| 保存未确认 | 刷新核对实际设置后再预览/明确保存；读回失败也可能已经写入Flash，不能断言未写入。 |

## 私人诊断

`status --host 当前主机名或IP`只读HTTP；`monitor --port PORT`打开USB，可能重启ESP32并显示私人日志，Ctrl+]退出。需要完整记录自然日时避免打开监视器。

串口115200，以下`\t`代表实际Tab：

- IP：本地地址；BLE_STATUS：目标/连接/新鲜标志，不显示地址。
- PAIR：私人设置码/URI，正常使用建议统一入口生成本地二维码页。
- RESOURCE_STATS：堆、栈、NVS容量；BACKUP_STATUS：备用摘要。
- BACKUP_STORE_CHECK：独立临时命名空间最大对象诊断，不注入日样本。
- BLE_DISCONNECT：停止蓝牙至重选/重启，不改冰箱设置。BLE_LIST / BLE_TARGET\t序号为同会话底层选择，优先用工具入口。
- CLOCK\tUnix秒、CTRL_TEMP\t数值、CTRL_MODE\t0或1、CTRL_POWER\t0或1是高级校时/控制请求，不是普通只读诊断，请优先用网页。

首次配对失败且**Controller列表为空**时有受限物理HAP_NEW_ID恢复命令，已配对会拒绝；不是清空整个家庭的通用按钮。优先从原家庭正常移除，并参考[Apple排查](https://support.apple.com/en-us/126198)。不要公开HAP_INFO原文、配对文件和Flash备份。

## 更新与USB恢复

正常更新重复同语言flash命令。只有一个应用槽，没有网络OTA或自动回滚。上传中断时按板厂说明进入USB下载模式，再用相同分区刷已知构建；本项目尚未完成更新中断救援实机演练。

完整Flash备份可能含凭据，恢复不相关备份/分区可能覆盖配置；统一入口不提供自动擦除或整片恢复。
