# 日常使用

[English](../en/usage.md) · [简体中文](usage.md) · [首页](../../README.zh-CN.md)

## 网页控制

同一局域网打开 **http://frostbridge.local**。默认一屏显示箱内实际温度、设备回读目标、调温输入/滑块、ECO/MAX与电源。滑块松手提交，或输入整数后点“应用”；有效温度范围也受设备新鲜回读限制。

排队不代表成功，请等待“设备已确认”。目标温度不代表箱内已达温，逻辑制冷启用也不代表压缩机正在运行。离线/过期会保留最后读数并停用控制，重要家庭/备用失败即使折叠仍显示。

首次访问默认英文，不按浏览器语言自动切换；点EN/中选择中文或英文，浏览器允许本地存储时会记住选择；不发送控制，不改时区，也不重命名家庭配件。“更多功能”内有每日备用、家庭、记录与连接详情。

## 家庭配件与自动化入口

| 中文安装 | 英文安装 | 用途 |
|---|---|---|
| 冰箱电源 | Fridge Power | 日常逻辑开关机 |
| 冰箱节能 | Fridge ECO | 开为ECO，关为MAX |
| 冰箱温控 | Fridge Temperature | 日常摄氏目标与逻辑启用 |
| 自动化电源 | Automation Power | 固定时间自动化输入 |
| 自动化节能 | Automation ECO | 固定时间自动化输入 |
| 自动化温控 | Automation Temperature | 固定时间自动化温度输入 |
| 连通检测 | Connectivity Probe | 可编程“单次按下”事件 |
| 检测回应 | Probe Reply | 往返检测回应，自动复位 |

编译/刷写时选择名称语言，已有家庭更新时保持相同配置；也可在家庭App自行重命名。网页切换语言不会隐式修改这些名字。

需要每日学习的固定时间自动化请只用“自动化”配件。普通网页/家庭/USB操作、在线可比较的面板修改建立手动覆盖，不作为学习样本。位置和外部传感器条件仍由HomeKit负责。

家庭App配置“连通检测→单次按下→检测回应→打开”，回应不控制冰箱。约60秒发出探测，15秒内接受回应，健康租期180秒；有加密TCP连接不代表自动化可执行。

## 实验性每日备用

软件和短时集成检查通过，但真实完整日学习、接管/恢复及48小时验收仍待完成。新安装的学习/备用默认**关闭**。

启用路径：更多功能→每日备用→启用学习和备用→预览并保存→核对影响→确认保存。启用结束旧覆盖；已有有效样本且需要接管时，可能立即对齐当前循环。关闭只停止学习/备用，不顺便关冰箱。设置保存与设备执行分别确认。

固定使用**北京时间UTC+8**，不随网页语言改变。保留最近完整自然日，不是滚动24小时，也不是家庭App规则导出。开启当天不完整。例如周一下午开启，首个合格日为周二，连续覆盖后周三00:00才封存。

- 仅记录实际收到并得到设备确认的固定时间自动化组件，每天最多64个温度/电源/模式动作。
- 已知记录、网络、探测、读数、校时或命令失败缺口使当天不完整，保留旧有效样本并显示日期和未更新原因。
- 完整但没有动作的一天是有效空白样本，替换旧样本，备用不主动改变冰箱。
- 当前候选存在RAM，重启使本日不完整，已封存样本保留；重新打开USB也可能导致这种重启。

有样本后，健康租期过期才可能接管，冷启动有首次探测宽限。无可靠时间、无有效样本或有有效覆盖时不操作。接管/重连只对齐当前循环目标，不逐条补发错过的开关机；真实往返恢复健康后交还HomeKit。

手动覆盖跨重连/重启保留，到已知样本下一动作边界，或后来入站且确认的自动化动作结束；未知时间/边界时继续保留，不猜过期。网页展示样本日期/年龄、今日缺口、覆盖及当前主控；日记录8条分页，版本变化时重新载入，不能混合不同样本页面。

持续供电可断网计时；彻底断电后无后备RTC，等待联网校时，或先核对手机/电脑时间，再用本机校时。失败动作不显示成功；恢复后重新判断当前目标。

## 供电、访问与记录

ESP32可用普通USB充电器，不依赖Mac持续运行。断电会中断本日覆盖，冰箱供电独立。

网页是局域网HTTP，可存明确HTTP地址的书签/主屏幕图标；当前不含HTTPS证书安装或公网控制，不要把80/1201转发到公网。

最近活动仅保留本次启动的有界记录。不要公开配对码、Wi-Fi凭据、蓝牙地址或原始日志。[故障排查](troubleshooting.md)列出正常恢复路径。
